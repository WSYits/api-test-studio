# C01：测试用例类型选择修复

前端传递 count 和 case_types；路由严格校验参数并去重，省略 case_types 兼容双选。
count 为必填 1–50 整数（不接受布尔、小数、字符串或空值）。
单选只使用所选类型；双选均分，奇数异常多一条，仅在已选类型中补足，不重复抽取候选组合。
候选不足返回 requested_count、actual_count 和提示；零条返回 400，在删除旧用例及采纳记录之前退出。
筛选和最终标签统一使用“全部子空间为 valid 才是正向”的规则。
原 HTTP 状态码断言保持不变。
